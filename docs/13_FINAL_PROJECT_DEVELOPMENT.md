## Current implementation

The baseline provides five courses, two learning resources, two career mappings, profile export/import, academic-rule checks, keyword/semantic/hybrid ranking, Gemini generation, source references, PCA and cosine inspection, and request traces. The development backend checks the relevant configured course and resource pages plus CSC120's reviewed program-requirement section on a submitted roadmap, then adds up to three validated course descriptions from configured foundation/core/track sections. It tracks source IDs for fetched fields, validates identity/edition, keeps separate freshness timestamps, handles source/cache failures, and reuses unchanged document embeddings. Prerequisite statements have separate citation chunks; changed or failed checks make the affected academic result unknown. Resource excerpts retain published versions separately from academic catalog years. See [runtime source checks](14_RUNTIME_SOURCES.md), [prerequisite evidence](15_PREREQUISITE_EVIDENCE.md), [bounded discovery](16_COURSE_DISCOVERY.md), and [resource checks](17_RESOURCE_SOURCES.md).

[Live opportunities](23_LIVE_OPPORTUNITIES.md) now check three configured public employer boards on an explicit search, with validated source links, separate provider dates, local title/location filters, and visible failures. A separate [posting-detail action](32_POSTING_DETAILS.md) requests a displayed listing's description with its own check time and metadata-change notices. This path uses no credentials or model calls. Adzuna live verification and OpenRouter integration remain unfinished. The original source repository passed 80 tests before this development work; historical measurements retain their dates and scope.

Citation membership does not establish claim accuracy. Production now limits the provider to [selecting application-owned statements](19_GROUNDED_EXPLANATIONS.md), with exact wording, type, citation, ownership, and context validation. It cannot insert arbitrary prose by calling a fact a recommendation. The four unresolved ECE conditions stay unknown. [Reviewed discovery](21_DISCOVERED_COURSE_RULES.md) binds CSC110's mathematics condition to exact current source/course identities; the [CS expansion](24_CS_FOUNDATION_COVERAGE.md) adds CSC144 and CSC210 conditions. Placement branches remain unknown and other discovered conditions remain unreviewed. Learning stages are preparation suggestions, not semester assignments or a complete degree audit.

The [query-interpretation follow-up](20_QUERY_INTERPRETATION.md) adds bounded domain aliases shared by coverage gates and retrieval. Specific questions can retain a directly relevant course without losing novice foundations or changing academic results. Unsupported requests skip source requests and provider initialization. Added search terms and question preferences are inspectable.

[Requested-course discovery](25_REQUESTED_COURSE_DISCOVERY.md) prioritizes explicit course codes before choosing which three new descriptions to download. [Reviewed phrase routing](26_COURSE_PHRASE_ROUTING.md) adds bounded title/topic phrases without requiring a code. It uses reviewed routing only within freshly verified selected sections, validates the downloaded identity, and exposes matched phrases and outcomes in the inspector. Remaining slots keep source order; no catalog-wide search or new academic interpretation is implied.
